# My Expense Tracker

A small expense-tracking website made with HTML, CSS and vanilla JavaScript.

## Features

- Add an expense with a name, amount, category and date.
- Edit an existing expense.
- Delete an expense.
- Filter the list by category.
- See total spending, spending for the current month and the number of expenses.
- Save records in the browser using `localStorage`.

## Run the project

1. Download and extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser. You can also use the VS Code Live Server extension.

No package installation or build command is needed.

## Project files

- `index.html` contains the page structure and form.
- `style.css` controls the layout, spacing, colours and responsive design.
- `script.js` handles adding, editing, deleting, filtering, calculations and browser storage.

## Notes

This is a frontend learning project. Data is stored in the browser on the device where the site is used. It does not use a server or a shared database, so expenses do not automatically sync between devices or browsers.
